# Лабораторна робота: DOM, BOM та Події (JavaScript)

Цей проєкт демонструє роботу з об'єктною моделлю документа (DOM), об'єктною моделлю браузера (BOM) та делегуванням подій за допомогою ванільного JavaScript.

## Функціонал
1. **Динамічний список задач (DOM Tree Manipulation):** Додавання, видалення та фільтрація задач (всі, активні, виконані).
2. **Оптимізація продуктивності:** Порівняння швидкості прямої вставки елементів у DOM та використання `DocumentFragment`.
3. **Single Page Application (SPA):** Навігація між сторінками без перезавантаження за допомогою BOM History API (`pushState`, `popstate`).
4. **Делегування подій:** Інтерактивна сітка карток, де обробник подій висить на батьківському контейнері, а не на кожній картці окремо.

## Технології
* HTML5 / CSS3 (Адаптивна верстка, Flexbox, CSS Grid)
* JavaScript (ES6+)
